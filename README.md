# Rapoarte de activitate de cercetare la doctorat

În România, studenții doctoranzi cu bursă trebuie să completeze în fiecare lună un raport cu activitatea de cercetare desfășurată. În spiritul transparenței, voi încărca aici toate rapoartele de cercetare pe care le-am scris pe parcursul doctoratului (sursa de adevăr fiind un proiect pe [Overleaf](https://www.overleaf.com/)).
